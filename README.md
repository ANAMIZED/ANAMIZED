### Research Alignment (FOUNDRY)

FOUNDRY (host-owned trust and memory for long-horizon agent swarms) separates untrusted proposal generation from host-owned verification + established-facts registry. ANAMIZED kernels implement the complementary production boundary: every mutation is forced through a fail-closed, event-sourced, evidence-gated promotion path (LRSI / RUI / Server-OS / OpenMesha / YodMCP / Proto-OS). Host owns the evaluator; agents propose.

- [docs/FOUNDRY.md on OpenGOS](https://github.com/ANAMIZED/OpenGOS/blob/main/docs/FOUNDRY.md) — grants propose / host verifies
- [docs/FOUNDRY.md on YodMCP](https://github.com/ANAMIZED/YodMCP/blob/main/docs/FOUNDRY.md) — facts registry
- [docs/FOUNDRY.md on RUI](https://github.com/ANAMIZED/Recursive-UltraIntelligence-RUI/blob/main/docs/FOUNDRY.md) — promotion gates
